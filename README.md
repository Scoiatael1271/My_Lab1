 Система учёта заказов интернет-магазина

Прототип промышленной системы учёта заказов, клиентов и товаров с графическим интерфейсом, хранением данных в JSON и возможностью анализа.

 Возможности

 Регистрация клиентов с проверкой email и телефона (регулярные выражения)
 Добавление товаров с ценой и категорией
 Создание заказов (клиент + товар + количество)
 Просмотр, сортировка заказов по дате и стоимости
 Экспорт / импорт данных в CSV и JSON
 Анализ данных:
  Топ-5 клиентов по числу заказов
  Динамика количества заказов по датам
  Граф связей клиентов (по городу или общим товарам)
 Полное покрытие ООП (инкапсуляция, наследование, полиморфизм)
 Unit-тесты
 Документация в docstrings (формат, близкий к numpydoc)

Установка и запуск

 1. Клонируйте репозиторий (или скачайте проект)

git clone <url-вашего-репозитория>
cd order_management

 2. Создайте виртуальное окружение

Windows:

python -m venv .venv
.venv\Scripts\activate


python3 -m venv .venv
source .venv/bin/activate


 3. Установите зависимости


pip install -r requirements.txt


 4. Запустите приложение


python main.py


 Как пользоваться

1. **Вкладка «Клиенты»** — введите ФИО, email, телефон и город, нажмите «Добавить клиента».
2. **Вкладка «Товары»** — введите название, цену и категорию, нажмите «Добавить товар».
3. **Вкладка «Заказы»** — выберите клиента и товар из списков, укажите количество и дату, нажмите «Создать заказ».
4. **Вкладка «Анализ данных»** — нажмите нужную кнопку анализа. Графики откроются в отдельном окне.

Данные автоматически сохраняются в папку `data/` в формате JSON.

 Запуск тестов

python -m unittest discover tests -v


 Используемые технологии

- Python 3.8+
- tkinter (GUI)
- pandas, matplotlib, seaborn, networkx (анализ)
- unittest (тесты)
- JSON / CSV (хранение и обмен данными)
